# Sistema de Pagamentos MySQL

Projeto acadêmico de banco de dados relacional desenvolvido com MySQL, com foco no gerenciamento de clientes, vendas, parcelas, pagamentos e solicitações de crédito.

## Objetivo

Implementar regras de negócio utilizando recursos do MySQL para organizar operações de pagamento e análise de crédito.

## Funcionalidades

* Cadastro e controle de clientes.
* Registro de vendas à vista e parceladas.
* Gerenciamento de parcelas e vencimentos.
* Registro de pagamentos.
* Cálculo de multas por atraso.
* Análise de solicitações de crédito com base no score.
* Consultas utilizando views.

## Tecnologias utilizadas

* MySQL 8
* SQL
* MySQL Workbench

## Recursos do banco de dados

* Tabelas relacionais.
* Functions.
* Stored procedures.
* Triggers.
* Views.

## Como executar

1. Instale o MySQL Server e o MySQL Workbench.
2. Clone ou baixe este repositório.
3. Execute os scripts SQL na ordem indicada.
4. Utilize os dados de demonstração para explorar as funcionalidades.

## Status do projeto

Projeto acadêmico em organização para portfólio. Algumas funcionalidades foram executadas localmente; os scripts serão organizados para facilitar a reprodução do ambiente.

## Aviso

Utilize um banco de dados de desenvolvimento para executar os scripts. Não utilize dados pessoais reais ou execute comandos sem verificar seus efeitos.
